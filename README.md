# GAMAXITY Floating Menu — Android source project

This is a starter Android project for a draggable floating bubble and a basic on-screen settings panel. It is source code, not a precompiled APK, and it has not been device-tested here.

## Easiest build from an Android phone (GitHub Actions)

This project includes `.github/workflows/build-apk.yml` so GitHub's cloud runner can build the debug APK without Android Studio on your phone.

1. Download `GAMAXITY_Floating_Menu_Source.zip` and extract it.
2. In your phone browser, sign in to GitHub and create a **new empty repository** (do not add a README/license).
3. Upload the contents of this folder to the repository, keeping the `.github/workflows/build-apk.yml` file and folder structure. GitHub's website may hide dot-folders in some upload flows; if it does, use GitHub's web editor to create `.github/workflows/build-apk.yml` and paste the workflow from this project.
4. Open the repository's **Actions** tab. If prompted, enable Actions.
5. Select **Build GAMAXITY Floating Menu APK**, tap **Run workflow**, then run it.
6. Wait for the workflow to finish successfully. Open the completed run and download the artifact named `GAMAXITY-Floating-Menu-debug-apk`.
7. Extract the downloaded artifact ZIP. It contains `app-debug.apk`. Tap it to install; Android may ask you to allow installs from that browser/file manager.

If the build fails, open the failed Actions run, copy the red error text or send a screenshot so the build can be fixed.

## Local build (computer with Android SDK)

Use Java 17, Android SDK platform 35, build-tools 35.0.0, and Gradle 8.7. From this folder run:

```bash
gradle --no-daemon assembleDebug
```

APK output: `app/build/outputs/apk/debug/app-debug.apk`.

## Use

1. Install and open the app.
2. Tap **ENABLE FLOATING MENU**.
3. Allow Android's **Display over other apps** permission.
4. Return to the app and tap **ENABLE FLOATING MENU** again.
5. Open Minecraft; drag the `G` bubble and tap it to open/close the panel.

## Important limits

- The toggles are demo/local UI state only. They do not change Minecraft hitboxes, aim, attacks, or server behavior.
- This project does not bypass anti-cheat or automate gameplay. Only use overlays and add-ons permitted by the relevant server.
- The APK generated by GitHub Actions is a debug build, not a Play Store release build.
